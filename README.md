# AWS-CLI-SETUP-ON-WINDOWS
Documentation for setting up and configuring the AWS command-line interface on a Windows system

Search for "AWS CLI install Windows" on Google

<img width="964" height="1080" alt="image" src="https://github.com/user-attachments/assets/235be6e4-f176-47c8-abb0-0ee85d4673a1" />

Be sure to install version 2, as it is the latest release

<img width="845" height="164" alt="image" src="https://github.com/user-attachments/assets/ec999c15-b2c0-4035-be15-1ba6fbe1b354" />

Once you click on the link shown in the image above, on the AWS page, in the left navigation pane under Get started, search for  and select Install/Update 

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/a547f562-8cab-47b8-917c-f1b536fdf499" />

Next, scroll down until you see "AWS CLI install instructions" and click the dropdown arrow for Windows

<img width="971" height="718" alt="image" src="https://github.com/user-attachments/assets/25957547-14c6-4e1e-8931-1548cab3fb2c" />
