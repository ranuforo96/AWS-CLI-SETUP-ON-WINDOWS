# AWS-CLI-SETUP-ON-WINDOWS
Documentation for setting up and configuring the AWS command-line interface on a Windows system

Search for "AWS CLI install Windows" on Google

<img width="964" height="1080" alt="image" src="https://github.com/user-attachments/assets/235be6e4-f176-47c8-abb0-0ee85d4673a1" />

Be sure to install version 2, as it is the latest release

<img width="845" height="164" alt="image" src="https://github.com/user-attachments/assets/ec999c15-b2c0-4035-be15-1ba6fbe1b354" />

Once you click on the link shown in the image above, on the AWS page, in the left navigation pane under Get started, search for  and select Install/Update 

<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/a547f562-8cab-47b8-917c-f1b536fdf499" />

Next, scroll down until you see "AWS CLI install instructions" and click the dropdown arrow for Windows

<img width="971" height="718" alt="image" src="https://github.com/user-attachments/assets/25957547-14c6-4e1e-8931-1548cab3fb2c" />

Then, click the download link for MSI installer - Current user

<img width="641" height="75" alt="image" src="https://github.com/user-attachments/assets/126cfeca-a579-4a4e-8d20-2f56a6275a75" />

Once the download has completed, you can now open and run your installer

<img width="591" height="331" alt="image" src="https://github.com/user-attachments/assets/3f7a20ec-8604-4393-9531-735d3ffc9b5e" />

Select Next on your installer 

<img width="1917" height="1077" alt="image" src="https://github.com/user-attachments/assets/4a4c3ca2-839c-46b5-85f2-1035ddb54d61" />
 
Check the box to accept the terms in the license agreement and click Next

<img width="586" height="458" alt="image" src="https://github.com/user-attachments/assets/deff9f7c-165e-45fc-8df6-9fbefe6844d9" />

Select Next again in the installer on the Custom Setup view 

<img width="582" height="463" alt="image" src="https://github.com/user-attachments/assets/fb621ba0-c77a-43dd-b212-872e72ba3337" />

You can then click Install 

<img width="585" height="460" alt="image" src="https://github.com/user-attachments/assets/d7b05633-8ade-41ac-b382-3f691d8e882e" />

Wait for the loading process to complete

<img width="583" height="459" alt="image" src="https://github.com/user-attachments/assets/625e93da-5405-4e03-bc88-23affc28d2ec" />
